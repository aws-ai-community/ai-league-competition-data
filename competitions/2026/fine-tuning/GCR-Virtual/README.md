# Fine-Tuning — Virtual GCR 2026

## Event Details

- **Event**: AWS AI League — Track 2 "Customize a Foundational Model", Virtual GCR (Greater China Region)
- **Date**: October 2026. Originally scheduled for the week of 12–16 October; postponed after a platform environment issue. The qualifier was re-run 27–29 October and the live finale was held on 30 October.
- **Format**: 1 online qualifier + 5 live finale questions
- **Qualifier**: fine-tune an Amazon Nova model with SageMaker AI serverless customization (SFT), as described in the Contest Terms (September 10 version).
- **Finale**: a prompt-engineering round, not a fine-tuned-model round (see below).

## Finale Format

Per the organisers' briefing email to finalists (30 October):

- All finalists were given the **same base model, Amazon Nova Pro** — the fine-tuned qualifier models were not used.
- **5 questions about re:Invent in Las Vegas**, in English.
- **90 seconds per question** (instead of the usual 45 seconds), to allow time for prompt engineering.

In the finalist console, each finalist edits a prompt and inference parameters (temperature, top-P, maximum length capped at 200 tokens), can run it to preview the answer, then makes a final submission before the timer ends.

Scoring followed the same per-question placement ladder as other regions: 40 / 30 / 20 / 10 / 0, with **question 5 worth double points** (80 / 60 / 40 / 20 / 0).

Question themes (paraphrased):

1. Beating jet lag between landing on Sunday and a 9 AM Monday session
2. Choosing between keynotes, breakouts, chalk talks, workshops, builders' sessions and code talks with about 10 seats
3. Splitting limited time between sessions, the expo and networking when the team expects learnings back
4. Networking at re:Invent as a non-native English speaker
5. (Double points) Planning a Thursday with fixed sessions in two venues, a budget, a step limit and a dinner deadline
